Code++

Simple code editor for C, C++, Python and text

Thông tin

Code++ là một trình soạn thảo mã nguồn đơn giản dành cho Windows.

Ứng dụng hỗ trợ soạn thảo các ngôn ngữ như C, C++ và Python, cùng với các tệp văn bản thông thường.

Code++ được phát triển bằng C++ sử dụng Win32 API và có thể sử dụng cùng MinGW để biên dịch mã nguồn.

Tính năng

  • Soạn thảo C
  • Soạn thảo C++
  • Soạn thảo Python
  • Soạn thảo file TXT
  • Syntax highlighting cơ bản
  • Tự động thụt dòng
  • Hỗ trợ TAB
  • Hỗ trợ UTF-8 và ANSI
  • Giao diện Windows đơn giản
